DISTRIBUTION WINDOWS

Le dossier contient l'application HTML et un lanceur portable sans npm/Node/Rust pour l'utilisateur.

IMPORTANT:
- Un vrai fichier binaire .exe Windows ne peut pas être compilé dans cet environnement Linux.
- installer.iss est prêt pour Inno Setup sur Windows et produit DynamicIsland-Setup.exe.
- Pour le portable, DynamicIsland-Portable.cmd lance l'application sans installation de npm.
